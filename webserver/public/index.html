@image images/sketch.png
Relative PNG path; following text is its caption. Drag the corner handle to resize.
@boxopen name / @boxclose name
Enclose notes between named markers. Nest or overlap boxes by choosing which name to close. Text below markers becomes a subtitle or footer.
@name
Start a borderless text note.
#to @name
Point to another note.
#from @source
Source → this note.
#to @class_name 2
Point to attribute row 2 (counting from 1).
#from @class_name 1
Start at attribute row 1.
#from 1 #to @target 2
This class’s row 1 → target class’s row 2.
#to @target 2 #from 1
The same row-to-row connection, target first.
#with @neighbor
Connect notes with a plain line, without an arrowhead or temporal ordering.
#use @target
Point to a target with a hollow triangle.
#color 222c3a
A thicker border in a six-digit hex color.
#border none
Let the text stand alone.
#border
Show a rounded border (rectangle for classes).
-- attribute
Add a row to a class.
#inherit @parent
Parent → child; hollow diamond at child.
